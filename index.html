Why KatanaKit

Sharp tools, zero surprises

Safe Results

Fallible async calls return `{ data, error, ok }` instead of throwing — HTTP, filesystem and every adapter share the same contract.

Zod everywhere

`src/types` is inferred from Zod schemas and API adapters validate every response at the boundary, so malformed payloads never leak.

Framework adapters

React, Vue, Solid, Svelte, Angular and Nuxt bindings over the same TanStack Query Core engine bundled with the package.

Node/Bun toolkit

Filesystem and path helpers with native errno codes, plus optional lazy faker for reproducible seed data and fixtures.

Zero side effects

Importing any module is safe — no fetch calls, no console logs, no storage writes, no top-level Node built-ins.

SSR-safe

Every infrastructure service guards or falls back gracefully outside the browser; Node-only APIs load through dynamic import.

Quick start ​

ts
import { defineApiConfig, useGetApi, useLogger } from "katanakit-js";

useLogger("boot");

// Register your APIs once
defineApiConfig({
  pokeapi: {
    baseUri: "https://pokeapi.co/api/v2",
    endpoints: { pokemonById: "/pokemon/:id/" },
  },
});

// Fetch with Safe Result — no try/catch needed for HTTP failures
const result = await useGetApi<{ name: string }>("pokeapi", "pokemonById", {
  params: { id: 25 },
});

if (result.ok) {
  console.log(result.data.name); // "pikachu"
} else {
  console.error(result.error.message);
}
