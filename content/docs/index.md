# KatanaKit documentation

`katanakit-js` is a framework-agnostic TypeScript service toolkit: HTTP with
Safe Results, Zod schemas, a TanStack-based query cache, browser infrastructure,
Node/Bun filesystem helpers, optional fake-data seeding and an OpenAI-compatible
assistant.
