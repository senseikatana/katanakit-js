# KatanaKit

KatanaKit — A sharp, framework-agnostic TypeScript service toolkit organized with hexagonal architecture.

## Features

- **Framework-agnostic** — Works with Astro, Nuxt, Express, and Vue
- **Hexagonal Architecture** — Clean separation of concerns
- **Fast & Lightweight** — Built with Astro for optimal performance
- **Comprehensive Docs** — Complete documentation with API reference, architecture, and guides
